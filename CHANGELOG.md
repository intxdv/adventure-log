# Changelog

All notable changes to the **Adventure Log** (`adventure-log`) web application will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [v1.0.0] - 2026-09-15

### 🚀 What's New / Added
- **[core]** Inisialisasi arsitektur frontend web **Adventure Log** berbasis React 19, Vite 8, dan TypeScript dengan strict modular structure.
- **[hero & header]** Interactive top-center cutout notch dock dengan inverted rounded ears, live Asia/Jakarta (WIB) clock, dan telemetry coordinates.
- **[3d-scene]** Interactive Three.js journal scene dengan dynamic camera parallax, atmospheric lighting, dan depth-masked landscape rendering.
- **[about & dossier]** Section field dossier interaktif dengan transisi tema nocturnal (dark forest), personal manifesto, archival metadata, dan disclosure drawer etimologi *Solivagant to Selvagant*.
- **[expeditions]** Katalog proyek interaktif dengan category filter (All, Apple Developer Academy, Engineering, Mobile Architecture), tactile project cards, dan dossier breakdown modal.
- **[arsenal]** Field capability matrix dengan 3 pilar spesialisasi (Creative Development, Mobile Architecture, Systems), tactile radar visualizer, dan rotary swipe carousel khusus tampilan mobile.
- **[footer]** 4-column colophon footer dengan edge-to-edge depth-masked landscape stage, foreground hill cutout, live status telemetry, dan frosted white glass plaque.
- **[preloader]** Smart asset readiness detection dengan RAF counter animation dan cinematic curtain reveal transition.
- **[seo & meta]** Konfigurasi lengkap OpenGraph preview (1.91:1 canvas / 1200x630), Twitter Cards, canonical URL untuk custom domain `selvagant.is-a.dev`, dan cache-busting query.

### 🔄 Changed & Improvements
- **[design-system]** Tipografi harmonis mengombinasikan Printvetica, Lufga, dan JetBrains Mono dengan rasio skala modular.
- **[accessibility]** Audit kontras warna di seluruh elemen teks dan token tema untuk memenuhi standar WCAG AA (4.5:1).
- **[responsive]** Optimasi fluid layout dari 320px mobile viewport hingga 4K ultra-wide display.

### ⚡ Performance
- **[rendering]** Enforce GPU layer promotion (`will-change: transform`) pada elemen scroll-linked dan notch dock untuk menjaga kestabilan 60 FPS.
- **[bundling]** Optimasi asset loading, code-splitting vendor chunks (Three.js, GSAP, React), dan kompresi gambar tekstur.
- **[linting]** Verifikasi konsistensi kode dengan Oxlint (0 errors, 0 warnings).
